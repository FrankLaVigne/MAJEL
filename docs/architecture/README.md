# Architecture

This directory will hold MAJEL's architecture documentation: descriptions of components, contracts, and how they fit together.

For now, the architectural thesis, principles, and conceptual diagram live in the [project README](../../README.md). Detailed documents will be added here as the design firms up through [experiments](../experiments/README.md) and [architecture decisions](../decisions/README.md).

Documents here should describe what exists or what has been decided. Label anything proposed or speculative as such.

## Planned topics

These are areas expected to need documentation. None have been written yet.

- **Vocabulary:** agents, capabilities, providers, interfaces, and trust boundaries
- **Control plane:** responsibilities, and its separation from the compute plane
- **Identity and state:** how agent identity persists across infrastructure
- **Capabilities and routing:** how requests are matched to providers
- **Policy and authority:** authorization and progressive authority levels
- **Trust boundaries:** isolation levels and when each applies
- **Adapters:** how heterogeneous agent runtimes integrate
- **Observability and audit:** what is recorded about agent activity
- **Failure and degradation:** behavior when agents, models, or providers are lost
